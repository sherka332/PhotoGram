# PhotoGram 2.0 — Complete structured version

## Included
- Instagram-style Home/feed
- Search
- Profile
- Follow/unfollow
- Image posts
- Like/comment/save/report
- Notifications API
- Direct chat
- Back navigation
- Separate app.js, admin.js, style.css and admin.css
- Separate Admin Panel
- Admin dashboard, users, posts, reports
- Render deployment files

## Render
Set `ADMIN_IDS` to your Telegram numeric user ID. Use a persistent database/storage for real production deployment; SQLite is included for simple testing.
